# lightdrift-libraw 1.0.1

Linux prebuilds now support AWS Lambda Node.js 22/24 on Amazon Linux 2023,
including arm64. Version 1.0.0 binaries were built on newer Ubuntu runners
and could require glibc symbols unavailable in Lambda, forcing a source build.

```bash
npm install lightdrift-libraw@^1.0.1
```

The Linux addon is built on Debian 11 with a glibc 2.31 ceiling and statically
linked C++ runtimes. CI checks symbol requirements and installs the final
tarball with lifecycle scripts disabled in the official Lambda Node.js 22/24
images on both x64 and arm64, then loads the matching prebuild and converts a
real RAW thumbnail to JPEG. These checks also gate npm publication.

This release also documents Electron 36 support and adds a Windows x64
Electron 36.9.5 packaged-consumer gate. The JavaScript and TypeScript API,
Node-API 8 ABI, LibRaw 0.22.2, and five-platform support matrix are unchanged.
